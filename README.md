# EventPlatform

## Описание проекта

EventPlatform — информационная система управления мероприятиями, предназначенная для автоматизации процессов управления и проведения мероприятий.

Система состоит из двух компонентов:

* веб-приложения для администраторов и организаторов мероприятий;
* мобильного приложения для участников мероприятий.

Веб-приложение позволяет создавать мероприятия, управлять пользователями и мероприятиями, отслеживать регистрации участников и осуществлять администрирование системы.

Мобильное приложение предоставляет участникам возможность просматривать список мероприятий, получать подробную информацию о событиях, покупать билеты на мероприятия и получать уведомления об изменениях.

## Запуск проекта

### 1. Клонирование репозитория

git clone https://github.com/abrazhko/eventplatform.git

### 2. Переход в каталог проекта

cd EventPlatform

### 3. Запуск контейнеров

docker compose up --build

### 4. Доступ к системе

После запуска веб-приложение будет доступно по адресу:

http://localhost:8080
